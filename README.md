# 微信聊天生成器

> 在线生成微信聊天及相关场景的模拟截图，支持文字、图片、红包、转账、语音等消息类型。所有编辑与图片生成均在浏览器本地完成，免登录、导出无次数限制。

## ✨ 功能特性

- **多种消息类型** — 文字、图片、红包、转账、语音、时间节点
- **手动添加消息** — 可视化编辑器，逐条添加任意类型消息
- **批量导入** — 支持 Markdown / 纯文本格式批量导入聊天记录
- **AI 模板 Prompt** — 复制提示词到豆包 / ChatGPT 等 AI，再导入返回的聊天文本；站内不直接调用 AI
- **独立工作页** — 聊天、批量聊天图、朋友圈、支付与转账、红包、个人资料和群信息各有编辑与预览区
- **批量聊天图** — 多组对话分别调整角色与样式，一次操作导出 ZIP
- **全局导出日志** — 在当前浏览器统一查看、搜索和筛选各工具的导出记录
- **自定义头像** — 为每个用户上传自定义头像
- **设为自己** — 任意用户可标记为"自己"，消息自动切换左右方向
- **外观设置** — 自定义气泡颜色、联系人名称、时间、信号、电量等
- **高清截图** — 一键导出 1125×2436 高清 PNG 图片
- **长截图** — 支持完整聊天记录长图导出
- **复制到剪贴板** — 截图直接复制，方便粘贴分享
- **本地创作** — 聊天草稿与导出日志保存在当前浏览器；批量队列仅在当前页面暂存

模拟素材仅用于内容创作与设计演示，请勿用于伪造凭证或欺骗他人。

## 📖 使用方法

### 方式一：文本导入

进入「聊天生成器」的内容导入区，在文本框中粘贴聊天记录，支持以下格式：

```
**【3月1日 14:32】**

**张三**：你好，在忙不？
**李四**：不忙，怎么了？
**张三**：[图片]
**李四**：[红包]恭喜发财
**张三**：[转账]200:饭钱
**李四**：[语音]5
```

### 方式二：手动添加

导入用户后，通过「添加消息」面板逐条添加消息，支持选择发送人和消息类型。

### 方式三：AI 生成

展开「用豆包 / AI 生成聊天记录」面板，复制 Prompt 发给 AI，将返回内容粘贴导入即可。

### 批量导出

进入「批量聊天图」，以独立一行 `---` 或 Markdown 标题分组粘贴多组文本，点击「添加到批量队列」，在编辑队列中调整后导出 ZIP。每批最多 50 组；修改文本后先更新预览。批量队列刷新后不能恢复，请及时下载。

## 🛠️ 技术栈

- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS v4**
- **Base UI** 交互组件
- **Lucide React** 图标库
- **html-to-image** 截图导出

## 🚀 本地开发

```bash
# 克隆仓库
git clone <本仓库地址>
cd wechat-chat-generator

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 单元测试与静态检查
npm test
npm run lint
```

本项目是纯前端应用，不依赖任何后端服务：不需要注册登录，导出也没有次数限制。

## 📝 消息格式参考

| 类型 | 格式 | 示例 |
|------|------|------|
| 文字 | `**用户名**：内容` | `**张三**：你好` |
| 图片 | `**用户名**：[图片]` 或 `**用户名**：[图片]URL` | `**张三**：[图片]` |
| 红包 | `**用户名**：[红包]备注` | `**张三**：[红包]恭喜发财` |
| 转账 | `**用户名**：[转账]金额:备注` | `**张三**：[转账]200:饭钱` |
| 语音 | `**用户名**：[语音]秒数` | `**张三**：[语音]5` |
| 时间 | `**【时间】**` | `**【3月1日 14:32】**` |
